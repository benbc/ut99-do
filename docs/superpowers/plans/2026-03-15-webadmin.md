# Web Admin Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Enable the UT99 built-in web admin behind a Caddy TLS reverse proxy, and remove CLI-based map management.

**Architecture:** `provision.sh` is extended to configure the UT99 web admin, install Caddy, and open port 443. The `ut99` script loses `cmd_maps` and gains `cmd_info`. `server/set-maps.sh` is deleted.

**Tech Stack:** Bash, Caddy (apt/official repo), UT99 web admin (built-in), UFW, systemd.

- [ ] **Step 3: Add web admin INI configuration**

Add after the final existing `sed -i` line (the `Difficulty=0` line):

```bash
echo "==> Configuring web admin..."
cat >> "$INI" <<EOF

[UWeb.WebServer]
Applications[0]=UTServerAdmin.UTServerAdmin
ApplicationPaths[0]=/ServerAdmin
Applications[1]=UTServerAdmin.UTImageServer
ApplicationPaths[1]=/images
DefaultApplication=0
bEnabled=True
ListenPort=5080
MaxConnections=30

[UTServerAdmin.UTServerAdmin]
AdminUsername=admin
AdminPassword=${WEBADMIN_PASSWORD}

[Engine.GameInfo]
AdminPassword=${INGAME_ADMIN_PASSWORD}
LoginDelaySeconds=1.000000
MaxLoginAttempts=50
EOF
chmod 600 "$INI"
```

> **Note on INI behaviour:** UT99 (OldUnreal 469) uses the last occurrence of a key when a section appears more than once. Appending to the end of the file reliably overrides any existing defaults.

- [ ] **Step 4: Open ports 80 and 443 in UFW**

Add after `ufw allow 7777:7779/udp > /dev/null`:
```bash
ufw allow 80/tcp > /dev/null
ufw allow 443/tcp > /dev/null
```

Port 80 is required for Let's Encrypt HTTP-01 certificate issuance. Port 443 is required for HTTPS traffic.

- [ ] **Step 5: Install Caddy**

Add after the UFW block:

```bash
echo "==> Installing Caddy..."
apt-get -o DPkg::Lock::Timeout=120 install -y -qq debian-keyring debian-archive-keyring apt-transport-https curl
curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/gpg.key' \
    | gpg --dearmor -o /usr/share/keyrings/caddy-stable-archive-keyring.gpg
curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/debian.deb.txt' \
    | tee /etc/apt/sources.list.d/caddy-stable.list
apt-get -o DPkg::Lock::Timeout=120 update -qq
apt-get -o DPkg::Lock::Timeout=120 install -y -qq caddy
```

- [ ] **Step 6: Write Caddyfile and enable the service**

Add immediately after the Caddy install block:

```bash
echo "==> Configuring Caddy..."
cat > /etc/caddy/Caddyfile <<EOF
${ADMIN_DOMAIN} {
    redir / /ServerAdmin/ permanent
    reverse_proxy localhost:5080
}
EOF
systemctl enable caddy > /dev/null
systemctl start caddy
```

The `redir / /ServerAdmin/ permanent` directive intercepts bare `/` requests in Caddy before they reach UT99, preventing UT99 from issuing a redirect to its internal LAN IP (a known gotcha).
